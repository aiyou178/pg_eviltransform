# PostgreSQL 19 GA verification and benchmarks

Date: 2026-11-22. Extension: pg_eviltransform 0.0.8, pgrx 0.20.0.

## Build and runtime

The PG19 CI entries and the benchmark/release build defaults now use the official
`postgres:19.0-trixie` image, available for amd64 and arm64. The PG18-base RC2
workaround and the extra prerelease repository setup were removed. PG15-18 CI
entries retain their matching PostgreSQL images.

Local verification used PostgreSQL 19.0, PostGIS 3.7.0, GEOS 3.15.0 and PROJ 9.9.0
on Docker Linux ARM64, with Rust 1.99.1 and Clang/libclang/LLVM 19. The existing
portable release settings are unchanged: opt-level=3, fat LTO, one codegen unit,
and C -O3. No CPU-native or instrumentation flags were added.

## Method

- Coordinates: 200,000 points, setseed(0.42), using the existing query shapes.
  The composed query includes WGS84 -> BD09 setup and BD09 -> Web Mercator.
  These are whole-query timings, not per-call timings.
- Jenks: 100,000 rows, 1,000 distinct values, 7 classes, work_mem=8MB. The
  CartoDB reference implementation sets its own random seed to 0.4567.
- JIT and parallel query workers disabled. The production release library was
  reinstalled after the test suite; all builds and tests finished before timing.
- One complete warm-up was excluded, followed by five serial measured rounds.
  Values are EXPLAIN ANALYZE Execution Time in milliseconds.

## Results

| Workload | Median ms | Min-max ms |
| --- | ---: | ---: |
| Native 4326 -> GCJ02 | 123.447 | 121.950-124.660 |
| Regex SQL 4326 -> GCJ02 | 5506.074 | 5456.403-5533.532 |
| Native 4326 -> BD09 -> 3857 | 325.736 | 323.299-340.397 |
| Regex SQL 4326 -> BD09 -> 3857 | 15526.996 | 15496.683-15567.133 |
| CartoDB SQL Jenks | 85.622 | 83.453-86.343 |
| Rust Jenks array | 10.087 | 10.002-10.593 |
| Rust Jenks aggregate | 9.067 | 8.982-9.073 |

These measurements verify the GA environment; they are not a controlled
comparison with the historical RC2 run and do not establish a GA speedup or
regression. The native and regex formulas use different Earth-radius constants;
the SQL coordinate timings are reference costs, not numeric-equivalence proof.

## Verification

- Both Docker toolchain images built on ARM64 using the PostgreSQL 19 GA base.
- All 28 release-profile tests passed on PG19.0: 15 database tests and 13 core tests.
- ARM64 DEB builds passed for PG15.20, PG16.16, PG17.12, PG18.7 and PG19.0. Each
  package contains its library, installation SQL and the exact 0.0.7 -> 0.0.8 migration.
- The published v0.0.8 PG19 ARM64 package loaded on GA and passed coordinate,
  CGCS2000 and Jenks smoke checks. The GA source rebuild matched the reference
  point EWKB and Jenks output from that package.
- Benchmark row counts and distinct counts were checked; Rust Jenks array and
  aggregate results matched. All benchmark rounds completed successfully.

The table contains ARM64 measurements only. Raw plans, intermediate output and
machine-specific details are retained locally outside the repository.

To reproduce, use a disposable database and run the
[coordinate](../../scripts/benchmark_pg18.sh) script with PG_MAJOR=19 and ROWS=200000,
and the [Jenks](../../scripts/benchmark_jenksbins.sh) script with ROWS=100000,
DISTINCT_VALUES=1000, BREAKS=7 and WORK_MEM=8MB. Run each once for warm-up and
five more times for measurement, exclude the warm-up, then take the median.
The scripts recreate their benchmark tables.
