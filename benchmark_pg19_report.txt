PG19 Beta 4 benchmark report (ROWS=200000)

Environment:
- Docker base image: postgres:19beta4-trixie
- PostgreSQL: 19beta4 (Debian 19~beta4-1.pgdg13+1)
- PostGIS: 3.7.0rc2, built from source against PG19 Beta 4
- pgrx: 0.19.3

Compared functions:
- ST_EvilTransform
- Regex_EvilTransform

Scenario: 4326 -> 990001
- ST_EvilTransform: 92.822 ms
- Regex_EvilTransform: 3057.853 ms

Scenario: 990002 -> 3857 (via 4326)
- ST_EvilTransform: 200.395 ms
- Regex_EvilTransform: 7916.158 ms
